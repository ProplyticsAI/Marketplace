## Cursor Cloud specific instructions

This is a minimal, zero-dependency Node.js (ESM) utility library. No `npm install` step is needed.

- **Run tests:** `node --test` (uses the built-in `node:test` runner; no external framework)
- **No build step:** Plain JavaScript, no transpilation required.
- **No lint configured:** The project has no linter set up.
- **No services:** No databases, Docker, or external APIs are needed.
